# DJ Set Builder

## Overview

An AI DJ assistant that helps plan a full set — from picking an opening track to mapping energy arcs and harmonic transitions. Uses Spotify's API for real track data (BPM, key, energy, danceability) and a RAG layer of DJ theory and technique. The standout feature is that it produces a real, playable Spotify playlist as output — not just a list of suggestions but an artefact the user can actually press play on. Targeted at bedroom DJs and enthusiasts who understand music but want help planning coherent, technically correct sets.

---

## RAG Knowledge Base

- **Camelot Wheel and Circle of Fifths:** complete compatibility rules for harmonic mixing, energy boost moves, relative minor/major transitions
- **Energy arc theory:** how to structure a set (slow open, build, peak hour, comedown), with documented examples from famous recorded sets and annotated tracklists
- **Genre-specific mixing conventions:** house, techno, drum & bass, hip-hop — each genre has its own rules about what's acceptable in terms of BPM jumps and key clashes
- **Beatmixing technique guides:** EQ blending, loop juggling, effects use, phrase matching, how to read a crowd
- **BPM range by genre:** reference table of typical BPMs for each major electronic genre
- **Influential DJ set tracklists:** documented and annotated sets from Boiler Room, Fabric, Dekmantel — used as structural examples
- **Common mixing mistakes:** what to avoid and why

## Tool Calls

| Tool | Inputs | Outputs |
|---|---|---|
| **Spotify track analyser** | Track name or Spotify URI | BPM, musical key (Camelot notation), energy (0–1), danceability (0–1), valence (0–1) |
| **Camelot key compatibility checker** | Two Camelot codes | Result: compatible / energy boost (+1) / relative minor (-3/+3) / clash — with explanation |
| **BPM transition advisor** | Two BPMs | Safe / risky / needs bridging track — with the acceptable range and half-time/double-time options |
| **Set sequencer** | List of tracks with audio features | Reordered sequence following energy arc logic, with transition notes between each pair |
| **Playlist exporter** | Ordered track list, playlist name | Creates an actual Spotify playlist in the user's account via OAuth |

## Technical Feasibility

### What makes it strong

It produces a real, tangible artefact — an actual Spotify playlist the user can hit play on. That makes it uniquely demo-friendly. The music theory for DJs (Camelot Wheel, BPM mixing, energy arcs) is well-documented and fairly compact, so the RAG layer is focused. Spotify's audio features API is genuinely good for what it measures. The Camelot compatibility logic is a clean, well-defined algorithm that translates directly into a tool function.

### How it would work technically

The user describes the kind of set they want (genre, duration, energy profile, occasion). The agent retrieves relevant mixing theory from the RAG KB. The user inputs track names; the Spotify analyser fetches audio features. The set sequencer tool applies energy arc logic to order them. The Camelot checker validates each transition. The user can iterate. Final output: export to Spotify.

### Drawbacks

1. **OAuth is genuinely annoying** — creating playlists requires full Spotify OAuth (redirect URI, token exchange, refresh tokens). Spotify has also tightened developer policies recently. Doable but adds meaningful complexity.
2. **Spotify's key detection is unreliable** — the key field is generated by an ML model and is frequently wrong, especially for tracks with ambiguous tonality. Mixed In Key is the industry standard for a reason.
3. **Underground artists are underrepresented** — if the set involves Zip, Donato Dozzy, or Objekt, Spotify either has nothing or sparse data. The tool degrades exactly where taste is most specific.
4. **Technical compatibility ≠ good mixing** — two tracks can share a Camelot key and similar BPMs and still sound terrible together due to texture, arrangement, or energy mismatch the audio features don't capture.
5. **Spotify's "energy" metric is generic** — a track scored 0.9 energy might be a dramatic orchestral swell, not a floor-ready techno drop. Energy + danceability + tempo must be combined.
6. **Rate limits** — analysing a 30-track set means 30 API calls just for audio features. Needs caching.
7. **Spotify ToS for commercial use** — free for school; a problem if the project goes commercial.

### Workarounds

| Problem | Workaround |
|---|---|
| OAuth complexity | Use spotipy library with Streamlit session state — reduces OAuth to ~20 lines |
| Bad key detection | Caveat clearly in UI; offer manual key override input |
| Underground artists | Fall back to Last.fm tags + manual BPM/key entry field |
| Energy metric limitations | Combine energy + danceability + tempo into a composite score; explain the formula in UI |
| Rate limits | Cache all audio feature lookups in session state; never re-fetch known tracks |

### Verdict

The strongest demo of all ideas — a real playlist is a compelling output. Also the most technically complex, primarily because of OAuth and the audio feature accuracy problems. Works best for mainstream electronic music (commercial house, pop-adjacent). Degrades for underground scenes. If your taste runs underground, the Festival → Club Mapper is better positioned in the same space. DJ.Studio is a direct competitor that already does this well — the differentiation is the RAG explanation layer and the conversational interface.

## Free Data & Content Boosts

- **GitHub open source Camelot implementations** — search "camelot wheel python"; reusable compatibility algorithms available
- **Spotify Web API** — free developer account gives access to audio features, track search, and playlist creation
- **Last.fm API** — free fallback for genre tags on artists not well-represented on Spotify; better for underground electronic music
- **Boiler Room / Resident Advisor tracklists** — publicly documented sets can be used as annotated examples in the KB

---

## Differentiation

RAG earns its place for the "why" layer — explaining *why* a transition works or doesn't, what energy arc theory says about track ordering, what the genre conventions are for the style of set being planned. DJ.Studio gives you the tool; your agent gives you the reasoning. The combination of Spotify API + RAG theory layer + conversational interface is genuinely different from existing tools, even if individual components are covered elsewhere. The main gap: the explanation and educational layer for DJs who are still learning.
