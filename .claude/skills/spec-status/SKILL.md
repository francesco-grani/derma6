Review the current state of the spec workflow and report:

1. Check `.claude/specs/` for any existing spec output documents (requirements, design, tasks, or similarly named files).
2. Check `.claude/agents/kfc/` to confirm which agent specs are available.
3. Report:
   - Which phases have completed output documents (with file paths)
   - Which phase is currently active or next in the queue
   - What the user needs to approve before proceeding
   - Which agent to invoke for the next step

Keep the report to 5-8 lines. Focus on actionable next steps.
