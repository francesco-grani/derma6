What the graph shows

All 178 imports flow downward or laterally — zero upward edges, zero cycles. The backend is a strict nine-layer DAG that can be built, loaded, and tested layer by layer.

↓ One-way dependency flow

Every edge points down the stack or sideways within a layer — never up. Transport (main, api/*) depends on the Agent and Tools; those depend on the RAG pipeline, Platform, and Data layers; everything bottoms out at Foundation. Because no arrow climbs, the import graph has no strongly-connected component larger than one — it is acyclic.

▤ Stable foundation

config (31 dependents) and schemas (21) sit at the very bottom and import almost nothing back. The most depended-upon code is also the most stable — the textbook stable-dependencies shape. Change ripples travel down into these modules, not out of them.

⇲ A single data seam

db/deps is imported by 15 modules yet is only 52 lines: a deliberate dependency-injection aggregator that hands out every store behind one import. High fan-in by design — a load-bearing wall, not a hotspot.

◈ Cohesive RAG subsystem

The rag/pipeline/* subtree (11 modules) is held together by lateral edges into a shared state and graph, with only downward links leaving it. High internal cohesion, low outward coupling — it reads and refactors as one self-contained unit.
