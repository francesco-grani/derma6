# LLM supplements retrieval gaps with training data; disclosure is binary, not granular

The Knowledge Base is intentionally scoped to 20 focused documents covering common actives and men's skincare. This scope means most answers require the LLM to blend retrieved context with its own training data to give a complete response. The system prompt instructs the model to prefer retrieved content but explicitly permits supplementation when the KB does not fully cover the question. Disclosure is binary: when KB sources are retrieved they are shown in a "Sources" expander; when nothing is retrieved, the model states it found no relevant documents before answering from training data. When sources are found, the blending is silent — individual sentences are not tagged as KB-sourced or training-sourced. This produces a RAGAs faithfulness score of ~0.80 (20% of answer content is not strictly grounded in retrieved context), which is an acceptable trade-off given the narrow KB scope and a user base that benefits from complete practical answers over formally grounded but incomplete ones. The upgrade path is inline per-sentence attribution (e.g. `[KB]` / `[general]` markers) once the KB is broad enough that most answers can be fully grounded.
